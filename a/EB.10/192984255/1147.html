CONCORDANT VERSES

CONCORDANT VERSES, such as have several words in common; but which, by the addition of other words, convey an opposite, at least a different meaning. Such are those.

Et { canis } in silva. { venatur } et omnia { servat. }
lupus { nutritur } { vestit. }
